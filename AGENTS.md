## Git workflow

- Always finish code or documentation changes with a commit unless the user explicitly asks not to commit.
- Use Conventional Commits.
- Write commit messages in English.
- Review `git status` before committing.
- Do not include unrelated files in commits.

## Language and UX

- Write user-facing UI text in pt-BR unless the user explicitly requests another language.
- Write code, identifiers, filenames, and technical implementation text in English unless there is a strong reason not to.

## Code style

- Avoid unnecessary code comments.
